# Adam Soppelsa — Projects Store

**Résumé (FR).** Portfolio web immersif : un disquaire indépendant des années 90 en 3D (Three.js), vu à la première personne depuis une position fixe — on tourne la tête et on zoome, on ne se déplace pas. Chaque projet est un vinyle que l'on sort du bac, retourne, ouvre et replace ; les applications ont leur propre rayon « SOPP AGENTS » ; le vieux disquaire est un agent IA (réel seulement une fois le Worker déployé avec une clé ; sinon mode catalogue, annoncé comme tel). Site statique pour GitHub Pages, bilingue FR/EN, avec une alternative 2D. Les pochettes sont des visuels provisoires ; le CV, l'e-mail, les réseaux, l'intitulé du Master 2 et la date de disponibilité restent à fournir (voir `docs/CONTENT.md`). Aucune mesure de performance sur appareil réel n'a encore été faite : voir `docs/ACCESSIBILITY_PERFORMANCE.md`.

---

An immersive portfolio set in a 1990s independent record shop ("SIDE A / RECORDS"). The visitor stands at one fixed spot, looks around and zooms; projects are physical vinyl records filed in six category bins, web applications have their own rack, and the old shopkeeper answers recruiters' questions (real AI only after the backend is deployed; otherwise a labelled catalogue mode). A 2D collection is the accessible/fallback path.

## Quick start

```bash
npm install
npm run dev        # http://localhost:8080/
npm run check      # syntax, data, paths, secrets, sizes
npm test           # shopkeeper knowledge / FAQ / Worker tests
```

Requires Node 22+ (development only: the site has no build step; Three.js is vendored). Deployment and the optional AI backend: [docs/DEPLOY.md](docs/DEPLOY.md), [docs/BACKEND.md](docs/BACKEND.md).

## Controls

| | Desktop | Smartphone |
| --- | --- | --- |
| Look around | Move the mouse (view follows the pointer, calm in the centre); arrow keys | Drag; optional gyroscope (permission) |
| Zoom | Mouse wheel; `+` / `-` | Pinch |
| Pick | Click a record, app case, the shopkeeper, the CV folder, business cards, the about plaque… | Tap |
| Handle a record | Drag to spin; buttons: flip (Side B), open sleeve, details, put back | Same, via on-screen buttons |
| Menu / header | `Esc` | Menu button |
| Re-centre | Header button | Header button |
| Position | Never changes (look and zoom only) | Never changes |

Mouse/keyboard shortcuts and mobile controls are implemented in `src/controls/look.js` and `src/ui/*`.

## Structure

```

src/main.js           entry
src/app.js            orchestrator (world ↔ UI ↔ audio ↔ AI)
src/core/             i18n, storage
src/ui/               intro, header, hud, record-dock, panels, assistant, directory2d, radio, toast
src/scene/            world, layout, room, furniture, props, people, records, artwork, textures,
                      materials, environment, lighting, postfx, interaction, quality, util, kit, assets
src/controls/look.js  fixed-position look controls
src/audio/            synthesized SFX/ambience + YouTube music (README inside)
src/ai/               shopkeeper client + local FAQ
src/data/             projects, applications, profile, knowledge  ← edit content here
worker/               Cloudflare Worker (AI proxy)
vendor/               Three.js r187 + add-ons (minified, generated by `npm run vendor`)
assets/fonts/         self-hosted fonts
scripts/              dev server, vendor build, checks
tests/                node:test suite + visual harness
docs/                 documentation
```
